Tokenary — Project Y

Structured meaning tokens for reliable AI

Tokenary is an infrastructure project that converts language into field-preserving JSON tokens with explicit null values. Once meaning is verified, AI systems stop re-deriving it repeatedly.

The problem

  • AI re-derives meaning every session
  • Interpretation drifts and contradicts itself
  • Ambiguity causes hallucination and wasted research
  • No audit trail for “what was known vs guessed”

The solution

  • Fixed schema with strict field preservation
  • Explicit null for unknowns
  • Local-first enrichment (GCIDE, Wiktionary)
  • Reversible, auditable updates

Executive Summary (2-page equivalent)

Project Y / Tokenary is a long-horizon infrastructure effort to reduce AI hallucination, ambiguity, and cognitive waste by treating meaning as data rather than inference.

Instead of asking models to “figure out” meaning repeatedly, Tokenary creates a persistent token layer where interpretation is explicit, inspectable, and reusable.

What exists today

  • 96,008 GCIDE tokens exported A–Z
  • Strict schema enforced across all tokens
  • Local Wiktionary SQLite joins for category / POS
  • Working enrichment pipeline with auditability

Measured efficiency impact (estimates)

  • Chat clarification reduction: 2–4×
  • Research speedup: 5–10×
  • Interpretation correctness: +30–60%
  • Hallucination risk: significantly reduced
Tokenary compounds. Every completed token permanently reduces future cost.

Current Status & Lessons

  • 87,000+ tokens surfaced the true scale of linguistic grounding
  • Category-only enrichment proved insufficient
  • Taxonomy inference requires controlled, domain-specific passes
  • This cannot be crowdsourced casually
The failure was not technical — it revealed the real cost of meaning.
