Structured meaning tokens for reliable AI workflows

Tokenary converts dictionary entries and linguistic concepts into a strict JSON schema with explicit null values — so meaning is reusable, auditable, and less prone to hallucination.

field-preserving JSON local-first enrichment audit trail & sampling reduces ambiguity & rework

Problem

AI systems repeatedly re-derive meaning from scratch, drift between sessions, and invent details under ambiguity.

Solution

A stable token spine: fixed fields, explicit nulls, enrichment rules, and verification metrics.

Outcome

Less chat friction, less web research, lower hallucination risk, higher interpretation signal-to-noise.

Quick facts

96,008 GCIDE tokens exported (A–Z)

Local enrichment via Wiktionary SQLite join (POS/labels/taxon hints). Schema preserved with nulls.

Pitch: Tokenary is a data infrastructure layer. Once a token is verified, future tasks stop paying the “derive meaning again” tax.

Why null matters

          

            Omitting fields causes silent drift and makes it impossible to tell whether something is “unknown” or “not applicable”.
            Tokenary uses explicit null so downstream systems can:
          

          
    
            
  • measure completeness (% fields filled)
    • 
            
  • avoid hallucination (“unknown stays unknown”)
    • 
            
  • verify changes (diffable tokens)
    • 
            
  • run confidence scoring + sampling audits
    • 
          

          

            
Rule: parsers/enrichers may only populate fields they can justify. Everything else stays null.
